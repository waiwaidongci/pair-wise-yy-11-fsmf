# hxyfront-62010 潜水气瓶充填 · 瓶组配比与交付冻结闭环

源提示词编号：5

潜水店气瓶充填前端系统。在原有“气瓶记录 + 待充队列 + 签收 + 单瓶历史”的基础上，升级为
**瓶组配比与交付冻结闭环**：

- **准入闸门**：气瓶按检验有效期与清洁等级（A 氧清洁 / B 普通 / C 油脂污染）准入。
  检验过期或油脂污染只能登记送检，检验合格回填后恢复准入；B 级瓶禁充 Trimix。
- **同组压力一致**：同组各瓶目标压力不同，或存在不可准入气瓶时，**整组拒绝**并留痕，
  可修订后重新入队（拒绝记录保留）。
- **充填复测**：录入实测氧/氦含量与静置复测压力；偏差超限（O₂ ±1%、He ±1%、压力 ±10bar）
  自动进入返工，返工复核**必须由另一人**完成（不能与充填操作员相同）。
- **交付冻结与失效重算**：签收即冻结。已签收瓶组若更换阀门（整组回待充填、气瓶留痕）
  或补录气源批次（参数仍有效、待重新签收），**原签收立即失效并重算瓶组状态**，历史完整保留。
- **刷新后一致**：事件溯源（event-sourced），队列、统计、界面均由同一不可变事件流推导，
  持久化在 localStorage（version 2）。

## 三层分离

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 规则（纯函数，无 React/存储） | `src/domain/rules.ts`、`constants.ts`、`stats.ts` | 准入判定、压力一致闸门、偏差判定、状态机折叠、复核人校验 |
| 存储（只追加事件） | `src/domain/store.ts` | 事件日志追加、订阅、localStorage 持久化；`flow.ts` 编排规则+存储 |
| 界面（只调用动作） | `src/ui/*`、`src/App.tsx` | 气瓶档案、建组、队列卡片、统计栏、时间线/历史 |

瓶组状态机：`draft → filling → awaiting-signoff → signed`；
偏差分支 `→ rework →（另一人复核合格）→ awaiting-signoff`；
冻结后 `signed → voided-awaiting-signoff`（补录批次）或 `→ draft`（换阀）。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无额外运行时依赖。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62010
```

## 校验

```bash
npm run typecheck  # tsc 严格类型检查
npm run smoke      # 38 项领域闭环冒烟测试（过期/污染送检、压力拒绝、返工双人复核、换阀/补录失效重算、刷新一致）
npm run build
```

首次打开会写入演示数据（含待充填、返工待复核、整组拒绝、签收失效待重签等场景），
可用页面右上角“重置演示数据”恢复。
