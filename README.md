# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

给潜水店使用的气瓶充填前端系统，已升级为**瓶组配比与交付冻结闭环**：

- **准入**：气瓶按检验有效期与清洁等级准入，过期或油脂污染只能送检，送检归队后重新入队
- **瓶组配比**：同组目标压力不一致时整组拒绝充填，移出不匹配气瓶后自动重算
- **充填复测**：充填后录入实测氧/氦含量与静置复测压力，偏差超限（氧 ±1%、氦 ±2%、压力 ±10bar）进入返工，返工充填合格后须另一人复核
- **交付冻结**：签收后更换阀门或补录气源批次，原签收立即失效并重算瓶组状态，历史全程保留
- 待充填队列、瓶组看板、签收单台账、单瓶历史与事件日志；数据持久化到 localStorage，刷新后队列与统计一致

## 代码结构（规则 / 存储 / 界面分离）

```
src/
  domain/    规则层：类型 + 纯函数（准入、偏差、瓶组状态、复核、签收失效）
  store/     存储层：状态转移、localStorage 持久化、演示数据
  ui/        界面层：登记、队列、充填、交付、历史各面板
  App.tsx    主框架：指标统计 + 页签导航
```
